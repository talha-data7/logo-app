Add your own logos

Choose SVG files made in Illustrator, Inkscape or Figma. You can pick many at once.

Tap here to choose SVG filesor drag them onto this box
For best results (in Illustrator):
  • Turn all text into shapes: select everything, then Type > Create Outlines. Logo Hive writes the business name itself.
  • Use flat colors (no gradients, no blur). Fewer colors = easier for customers to recolor.
  • Remove clipping masks: Object > Clipping Mask > Release.
  • Save with File > Save As > SVG. Do not include the business name in the symbol.

Unlock codes

When a customer pays you, send them one code. They paste it in the app and get the number of logos you set in Settings (default 3).

  • After making codes, go to Publish and upload the new config.js. Codes only work after that.
  • The list below is saved only in this browser. Press Download my code list to keep a safe copy.
  • The website only stores a scrambled form of each code, so nobody can read the codes from your website.
  • One code works once on each phone/computer. Do not post codes publicly.

Publish your changes

Download two small files, then upload them to GitHub. Your website updates by itself in about a minute.

    Download blocked? Edge/Chrome sometimes blocks .js files. Click the download arrow at the top of the browser and choose Keep. Or use these buttons and paste the text into the file on GitHub (open the file → pencil icon → select all → paste → Commit).

    Then upload them

    1. Open your project on GitHub (the repository where the website files are).
    2. Tap Add file → Upload files.
    3. Drag in the downloaded config.js and custom.js. Same names replace the old ones.
    4. Tap Commit changes. Wait one minute and refresh your website.

    If you made no change to a file you do not need to upload it again.
